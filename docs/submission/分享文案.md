**正文**

```
我学食品检验检测，但高数、化学、AI 的课都在自学，资料散在几百个 PDF 和笔记里。
最烦的不是找不到，是找回来那份不知道它在哪一章、跟哪个概念连着。

所以我做了一个能"走进去"的知识库。

打开是八角大厅，六个方向六条走廊。挑一条走到底，穿过发光的门框，就是那个学科的阅览室——三面书架墙，一章一根书脊，书名直接烤在架子上。站到架子前把准星对准书脊点一下，右边就跳出那一章正文，公式和图示都是离线的。

走法：WASD 走动，Shift 快走，鼠标转向，F 回俯瞰。房间两面侧墙各有一扇门，走过去就是隔壁学科。

技术上是 Three.js 单条渲染路径，零外部资产（墙面木纹书脊星空全是 canvas 现算，产物里没有一张图片），9.99 MiB，零外部请求。桌面 60.7 fps。

参赛项目，用 Qoder 开发和部署，线上能直接走：
🔗 zhishu-matrix-9hy96msjm5u.qoder.zone

#2026Qoder高校创造力大赛 #Qoder #学习工具 #知识库 #Three.js #前端
```
