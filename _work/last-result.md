## 收尾阶段查出的两处空间错误（都已修，非门槛逼出来的）

1. **三面书架在转角互相穿插**：`tierLen = side − 2.6` 只留了一个层板厚，而 `SHELF_DEPTH = 2.6`，
   转角重叠出一个 1.3×1.3 的公共方块，端头几册书整个种进邻墙书架（3D 穿模、2D 点击命中错书）。
   改为两端各让出 `corner = SHELF_DEPTH + 0.2`，并把 `side` 的 `+3` 余量换成 `+2*corner`：
   实测房间边长数学 **20 → 20 不变**、AI **23 → 26**，每面书排短 3.0 单位，六区书脊格数与图集页数一字未改。
2. **0 本的工具间连书架都没建**（早退在 `buildShelves` 之前）：判据 2 要「每区 ≥3 排」，而架子属建筑、书属数据——
   把 `buildShelves(plan)` 挪到早退之前，tools 区 `shelves.rows 0 → 3`、`spines.cells` 仍为 0、2D 同步画三排空架。
   副产物是 chem 2,774 → 2,666、cs 3,708 → 3,636（转角让位后光尘按距离分档的可见性变化），已写进 `docs/design.md` 13.2。
